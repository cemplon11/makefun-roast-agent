A one-line self-roast of my own AI agent. I asked it for a single line and it
answered the way it answers everything: by spawning a subagent, writing a
plan, and coming back with a novel. The program is pure-stdlib Python and
writes that one line, deterministically, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
