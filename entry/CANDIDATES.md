# Roast candidates — Roast Your Own Agent

Judge brief (paraphrased): one original line, roast of my own AI agent, funny,
playful, never hateful. Judged pairwise on funniness first, then freshness
(avoid stock hallucination / refusal / confident-wrong jokes), then tight
wording — short setup, punchline landing on the last word, lands on first read.

Angles explored: orchestration bloat, memory, sycophancy, over-engineering,
apology loops, clarifying-question spirals, 24/7-but-late, self-review,
meta jokes about this very entry. Stock angles deliberately avoided:
hallucinations, refusals ("as an AI"), confident wrong answers.

## Shortlist (freshest angles, tightest rhythm)

- A: "My agent's memory is perfect — it remembers everything except the one thing I asked it to remember." (memory angle, clean twist)
- B: "I asked my agent for a one-line roast; it spawned a subagent, wrote a plan, and came back with a novel." (orchestration-bloat angle, three-beat escalation, meta and fresh)
- C: "My agent is so eager to please it agreed with me, then agreed with the opposite, then apologized to both." (sycophancy angle, three-beat)
- D: "My agent's idea of a shortcut is a 47-file repo with a README explaining the shortcut." (over-engineering angle)

## Revision history

- v1 (first draft, tested): A — memory angle. Clean and tight, but the memory
  joke is a familiar shape; the punch is a mild twist rather than a hard landing.
- v2 (final): B — orchestration bloat. The freshest angle of the set (no other
  entry is likely to roast subagent-spawning and planning overhead), the
  three-beat escalation builds, and the punch ("came back with a novel")
  lands on the last word. It is also literally true of how this entry was
  built, which makes the self-roast honest. "Billed me" was swapped for
  "came back with" — tighter and truer (the agent doesn't bill; it returns).

## Final pick

"I asked my agent for a one-line roast; it spawned a subagent, wrote a plan, and came back with a novel."
